# Codex Ghost

This is an independent public source repository. Keep changes inside this repository.
Do not commit runtime account data, tokens, local logs, recovery archives or private paths.
Use synthetic fixtures for automated tests; live quota reads require an explicit local request.
Keep the character pixel based, retain reduced-motion behavior, and use no remote renderer.
Run `npm test` for rendering changes and `bash tests/quota.sh` for quota parser changes.
A build is not a Finder/device test. Keep signing/distribution status accurate.
